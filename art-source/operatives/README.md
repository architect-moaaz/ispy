# Operative models (Meshy image-to-3D, 2026-11-13)

Ten textured A-pose operatives generated on meshy.ai (Meshy 7.1, Ultra 2K, 2K textures, Private license).
`m1` and `f1` come from Moaaz's reference render; the other eight come from the matching concept sheets here.

| file | who |
|---|---|
| m1-reference-hooded-coat | reference male: hooded long coat, armored suit |
| m2-lean-hooded-coat | lean dark-skinned operative, hooded long coat |
| m3-brawler-bomber | bearded brawler, cropped bomber, harness |
| m4-slim-bodysuit | slim East Asian operative, seamed bodysuit, short hooded shell |
| m5-veteran-trench | silver-haired veteran, open leather trench, scarf |
| f1-reference-tactical-suit | reference female: armored tactical suit |
| f2-hooded-coat | hooded long coat cinched at the waist |
| f3-braid-moto-harness | braided operative, moto jacket, harness |
| f4-runner-vest | runner build, sleeveless armored vest |
| f5-platinum-asym-coat | platinum bob, long asymmetric coat |

These are source assets: 0.7–1.0M triangles each, 27–66 MB, unrigged. They are NOT bundled in the app and
are git-ignored. Before use in the street view each needs a low-poly remesh and auto-rig (Meshy Animate tab),
then the operative loader has to be adapted from the Quaternius skeleton to Meshy's.
